# PCB Design Project – ESP32 & MPU6050

## 1. Project Overview
This project focuses on designing a custom Printed Circuit Board (PCB) using EasyEDA for an ESP32 and MPU6050-based electronics system. The objective is to organise electronic components, establish proper electrical connections and create a compact PCB layout for hardware implementation.

## 2. Project Objectives
- Design a custom PCB layout using EasyEDA.
- Understand schematic design and PCB routing.
- Learn component placement and footprint selection.
- Establish proper connections between electronic components.
- Develop practical knowledge of hardware design.

## 3. Software Used
- EasyEDA – Schematic and PCB Design
- ESP32 – Microcontroller platform
- MPU6050 – Motion sensor module

## 4. Design Process
1. Identified the required electronic components.
2. Selected appropriate component footprints.
3. Created the circuit schematic.
4. Transferred the schematic into PCB layout.
5. Arranged components according to the circuit requirements.
6. Designed PCB tracks and routing.
7. Reviewed the PCB layout for design consistency.

## 5. Skills Learned
- PCB layout designing
- Electronic component identification
- Schematic understanding
- Footprint selection
- PCB routing
- Hardware design fundamentals

## 6. Project Status
PCB layout design completed. Hardware fabrication and physical testing are pending.

## 7. Future Improvements
- Manufacture the designed PCB.
- Test electrical connections and functionality.
- Debug hardware-level issues.
- Improve PCB layout and power management.
